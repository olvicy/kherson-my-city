# 💙💛 Мій Херсон. Місто наших сердець

Інтерактивний вебпроєкт, створений до Дня міста Херсона. Проєкт об'єднує учнів, вчителів та гостей спільноти навколо спогадів, улюблених місць, асоціацій та мрій про майбутнє відновлення міста.

## 📸 Авторство фотографій
Усі фотографії Херсона, використані в інтерактивній галереї проєкту, належать авторству **Олександра Корнякова (Alexandr Kornyakov)** та опубліковані у відкритому доступі сервісу Google Maps.

## 🛠 Технологічний стек
* **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS (CDN).
* **Backend & Database:** Google Apps Script (`doPost`), Google Sheets API.
* **Storage & State:** `sessionStorage` (збереження чернетки сесії), `localStorage` (локальна статистика).
* **Hosting:** GitHub Pages.

## ✨ Основні можливості
* 3-кроковий інтерактивний сценарій із навігацією та збереженням стану при оновленні сторінки (`F5`).
* Підтримка багатьох класів та спільнот (10–11 класи, Вчителі, Гості) з можливістю додавання нових груп.
* Пряма синхронізація відповідей із Google Таблицею в режимі реального часу.
* Публічний перегляд статистики вподобань фотографій після проходження.
* Захищена паролем Панель розробника для аналізу якісних текстових відповідей.
